# Astro Fine — Aplicación de finanzas personales

Astro Fine es una aplicación de finanzas personales desarrollada como proyecto de software. Su objetivo es facilitar el seguimiento y análisis de los gastos mediante una aplicación móvil, un backend y herramientas de Machine Learning.

El proyecto integra el desarrollo frontend y backend, la gestión de datos y un modelo de aprendizaje automático para el análisis y la predicción de gastos.

## Características principales

- **Aplicación frontend:** interfaz desarrollada con Flutter y Dart.
- **Backend:** API desarrollada con Python y FastAPI.
- **Base de datos:** PostgreSQL para la gestión de la información.
- **Machine Learning:** integración de un modelo de aprendizaje automático para el análisis y la predicción de gastos.
- **API REST:** comunicación entre la aplicación y el backend.
- **Despliegue del backend:** utilización de Render como plataforma de alojamiento.

## Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| Flutter | Desarrollo de la interfaz de usuario |
| Dart | Lenguaje del frontend |
| Python | Desarrollo del backend y procesamiento de datos |
| FastAPI | Construcción de la API |
| PostgreSQL | Gestión de la base de datos |
| scikit-learn | Desarrollo e integración de Machine Learning |
| Render | Despliegue del backend |
| Git y GitHub | Control de versiones y gestión del código |

## Arquitectura del proyecto

Astro Fine integra diferentes componentes que trabajan conjuntamente:

- **Frontend:** permite al usuario interactuar con la aplicación.
- **Backend:** procesa las solicitudes y conecta los componentes del sistema.
- **Base de datos:** almacena la información utilizada por la aplicación.
- **Modelo de Machine Learning:** permite realizar análisis y predicciones relacionados con los gastos.

## Objetivo del proyecto

Desarrollar una solución tecnológica que combine el desarrollo de aplicaciones, las bases de datos, las API y el aprendizaje automático para facilitar el análisis de las finanzas personales.
